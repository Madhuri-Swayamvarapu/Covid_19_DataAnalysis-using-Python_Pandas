# Covid_19_DataAnalysis-using-Python_Pandas

**Project Description**

This project focuses on analyzing a COVID-19 dataset using Python and Pandas. The dataset contains information about Confirmed, Deaths, and Recovered cases from different regions across the world till 29-April-2020.

The main objective of this project is to perform data cleaning, filtering, sorting, grouping, and visualization operations to gain meaningful insights from the dataset.

The analysis is carried out using Jupyter Notebook along with Python libraries such as Pandas, Seaborn, and Matplotlib.

**Project Objectives**

**This project answers the following analytical questions:**

  1.Show the number of Confirmed, Deaths, and Recovered cases in each region.
  2.Remove all records where Confirmed cases are less than 10.
  3.Find the region with the maximum number of Confirmed cases.
  4.Find the region with the minimum number of Death cases.
  5.Display Confirmed, Deaths, and Recovered cases reported from India till 29-April-2020.
  6.Sort the dataset:By Confirmed cases in ascending order
